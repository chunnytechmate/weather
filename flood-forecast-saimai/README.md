## อ่านยังไงให้รู้ว่าน้ำฝั่งเราจะลดเมื่อไหร่

ดู **ไฟจราจร 7 ดวง** บนสุดทุกเช้า:

1. ฝน 24 ชม. ที่ซอย — ฝนคือการเติมน้ำใหม่
2. สะพานนวลฉวี (ปากคลองลาดพร้าว) — ประตูน้ำของฝั่งเหนือ กทม.: ต่ำกว่า 2.0 ม. = ระบายออกได้เร็ว
3. ปตร.คลองสองสายใต้ (เซ็นเซอร์ กทม. เกณฑ์ทางการ: เตือนภัย 1.1 / วิกฤต 1.8 ม.)
4. มวลน้ำเหนือ (บางปะอิน+สามเสน) — ถ้าขึ้นแรง อย่าคาดหวังให้ปลายทางลดเร็ว
5. น้ำหนุนทะเล (spring tide) — ช่วงน้ำหนุนประตูน้ำเปิดได้เฉพาะกลางวัน
6. ฝนภาคเหนือ 72 ชม. — สัญญาณมวลน้ำรอบใหม่ (lag ~3–7 วันถึง กทม.)
7. เขื่อนต้นน้ำ (สิริกิติ์/ภูมิพล/กิ่วลม) — ≥100% ความจุ = ต้องระบายเพิ่ม

**เมื่อ 5 ใน 7 ดวงเขียว และเซ็นเซอร์คลองสองต่ำกว่า 1.1 ม. → น้ำหน้าบ้านจะลดชัดภายในวันนั้นถึง 1 วัน**

## ระดับน้ำปกติ + ประวัติย้อนหลัง 60 วัน (เส้นฟ้าบนหลอด + กราฟ combo)

ทุกหลอดมี **เส้นฟ้า = ระดับน้ำปกติ** กำกับ พร้อมข้อความใต้หลอด "ปกติ ~X.XX ม. (สูงกว่าปกติ +Y ซม.)" — และท้ายหน้ามีแผง **"ประวัติจริง 60 วัน + พยากรณ์ 30 วัน รายสถานี"** (กราฟ 10 สถานี: เส้น teal = ข้อมูลจริง, เส้นส้ม = พยากรณ์+แถบคาด, เส้นประฟ้า = ปกติ, เส้นประแดง = เกณฑ์):

- ข้อมูลย้อนหลัง 60 วัน (15 นาที/จุด) จาก thaiwater `waterlevel_graph` — ต้องใส่ `station_type=tele_waterlevel` (กรมชลฯ) / `tele_canal` (เซ็นเซอร์ กทม.) ไม่งั้นได้ค่า null/500
- ปกติ = median ของค่าเฉลี่ยรายวัน ตัด 7 วันช่วงเหตุการณ์ออก · กรองค่าชำรุด (ต่ำกว่า −1.5 ม.) · สถานีที่ระดับขึ้นตามฤดูกาลเกิน 1.5 ม. ใช้ค่ายุคต้นของประวัติ (ติดป้าย oldest10)
- เซ็นเซอร์ กทม. มี 2 เส้นอ้างอิง: ปกติตามสถิติ + เกณฑ์เตือนภัย (= น้ำไม่ท่วมซอย)
- ใน tab forecast มี badge "คาดน้ำไม่ท่วมซอย ~วันที่" / "✓ แล้ว" / "ยังเกินปกติทั้ง 30 วัน" ต่อสถานี
- รีเฟรชอัตโนมัติทุก 24 ชม. (`scripts/normal_levels.py` → `data/normal_levels.json` + `data/station_history.json`)

## Forecast รายวัน 30 วัน (tab เลือกวัน)

ท้ายหน้ามี tab วันที่ 30 วันข้างหน้า — กดแล้วเห็นค่าทำนายระดับน้ำรายสถานี + ช่วงความไม่แน่นอน (lo–hi) + สีสถานะต่อเกณฑ์ · กรอบปุ่มเส้นประ = tier 2 (คาดหมายฤดูกาล)

โมเดล (`scripts/forecast_days.py`) — lag-route hydrograph: `h(t) = h(t-1) + rise − drain`
- **rise** = wave จากส่วนเกินเหนือตลิ่งบางปะอิน ×0.30 (lag 1 วัน/ตอน — ตัวขับหลักตอนมวลน้ำเหนือมา) + ฝนเหนือ (lag 3 วัน) + ฝนท้องถิ่น + momentum สถานีจากค่าเฉลี่ย 18 ชม.
- **drain** = K · recession × ตัวคูณน้ำหนุน (คำนวณจากเฟสดวงจันทร์ 1.0 น้ำแล้ง → 0.45 spring) × ส่วนเกินเหนือระดับล่าง
- **2 tier ของ input ฝน**: วัน 1–16 ใช้ NWP (Open-Meteo forecast) / วัน 17–30 ใช้ Seasonal API (ECMWF SEAS5) เรียบด้วย rolling mean 5 วัน
- h0 ของทุกสถานี = ค่าเฉลี่ย 18 ชม. (dedupe ตาม timestamp ค่าอ่าน) เพื่อกลบวัฏจักรน้ำหนุนและค่า stale
- ค่าเริ่มต้น K อิงสถิติ recession ปี 2554 (rain_coef ปรับสเกลใหม่ 28 ก.ย. เพราะค่าเดิมสูงผิดสัดส่วน) — จะถูกแทนด้วยค่า fit จากประวัติ snapshot ของเราเองเมื่อสะสมพอ
- ความไม่แน่นอนสะสม ±(8 + 9·i) ซม. มีเพดาน 90–100 ซม. + ขยายเพิ่มใน tier 2

## โครงสร้าง

- `dashboard.html` — dashboard (เปิด offline ได้ ยกเว้นพื้นหลังแผนที่ต้องออนไลน์)
- `scripts/fetch_snapshot.py` — ดึงข้อมูลครบ 30 สถานี (ต้นน้ำ→ปากน้ำ) + เขื่อน + เซ็นเซอร์ กทม. + ฝนซอย 16 วัน + ฝนเหนือ 16 วัน + seasonal (SEAS5) 35 วัน (รีเฟรชระดับปกติทุก 24 ชม.)
- `scripts/forecast_days.py` — โมเดล forecast รายวัน 30 วัน → `data/fc_days.json`
- `scripts/normal_levels.py` — คำนวณระดับน้ำปกติจากประวัติ 60 วัน → `data/normal_levels.json`
- `scripts/build_dashboard.py` — ประกอบ dashboard จาก snapshots + forecast
- `scripts/nearby_gauges.py`, `scripts/forecast_model.py` — วิเคราะห์ครั้งแรก (รายงานใน REPORT.md)
- `data/snapshots/` — ประวัติระดับน้ำสะสมรายชั่วโมง, `data/fc_days.json` — forecast, `data/normal_levels.json` — ระดับปกติ
- `REPORT.md` — รายงาน forecast ฉบับล่าสุด (28 ก.ย. — verification + forecast 30 วัน)
- `TOOLS_INSTALLED.md`, `uninstall.sh` — รายการติดตั้ง (cron + LaunchAgent) + ถอนทิ้งทั้งหมด
