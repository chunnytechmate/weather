## อ่านยังไงให้รู้ว่าน้ำฝั่งเราจะลดเมื่อไหร่

ดู **ไฟจราจร 7 ดวง** บนสุดทุกเช้า:

1. ฝน 24 ชม. ที่ซอย: ฝนคือการเติมน้ำใหม่
2. สะพานนวลฉวี (ปากคลองลาดพร้าว), ประตูน้ำของฝั่งเหนือ กทม.: ต่ำกว่า 2.0 ม. = ระบายออกได้เร็ว
3. ปตร.คลองสองสายใต้ (เซ็นเซอร์ กทม. เกณฑ์ทางการ: เตือนภัย 1.1 / วิกฤต 1.8 ม.)
4. มวลน้ำเหนือ (บางปะอิน+สามเสน): ถ้าขึ้นแรง อย่าคาดหวังให้ปลายทางลดเร็ว
5. น้ำหนุนทะเล (spring tide): ช่วงน้ำหนุนประตูน้ำเปิดได้เฉพาะกลางวัน
6. ฝนภาคเหนือ 72 ชม.: สัญญาณมวลน้ำรอบใหม่ (lag ~3–7 วันถึง กทม.)
7. เขื่อนต้นน้ำ (สิริกิติ์/ภูมิพล/กิ่วลม): ≥100% ความจุ = ต้องระบายเพิ่ม

**เมื่อ 5 ใน 7 ดวงเขียว และเซ็นเซอร์คลองสองต่ำกว่า 1.1 ม. → น้ำหน้าบ้านจะลดชัดภายในวันนั้นถึง 1 วัน**

## ระดับน้ำปกติ + ประวัติย้อนหลัง 60 วัน (เส้นฟ้าบนหลอด + กราฟ combo)

ทุกหลอดมี **เส้นฟ้า = ระดับน้ำปกติ** กำกับ พร้อมข้อความใต้หลอด "ปกติ ~X.XX ม. (สูงกว่าปกติ +Y ซม.)" และกราฟ timeline ของแต่ละสถานี (เส้น teal = ข้อมูลจริง 60 วัน, เส้นส้ม = พยากรณ์ 90 วัน+แถบคาด, เส้นประฟ้า = ปกติ, เส้นประแดง = เกณฑ์):

- ข้อมูลย้อนหลัง 60 วัน (15 นาที/จุด) จาก thaiwater `waterlevel_graph`: ต้องใส่ `station_type=tele_waterlevel` (กรมชลฯ) / `tele_canal` (เซ็นเซอร์ กทม.) ไม่งั้นได้ค่า null/500
- ปกติ = median ของค่าเฉลี่ยรายวัน ตัด 7 วันช่วงเหตุการณ์ออก · กรองค่าชำรุด (ต่ำกว่า −1.5 ม.) · สถานีที่ระดับขึ้นตามฤดูกาลเกิน 1.5 ม. ใช้ค่ายุคต้นของประวัติ (ติดป้าย oldest10)
- เซ็นเซอร์ กทม. มี 2 เส้นอ้างอิง: ปกติตามสถิติ + เกณฑ์เตือนภัย (= น้ำไม่ท่วมซอย)
- ในตารางรายสถานีมี pill เทียบปกติ: เขียว = ใกล้ปกติ / ส้ม = สูงกว่าปกติ / แดง = สูงมากหรือเกินเกณฑ์
- รีเฟรชอัตโนมัติทุก 24 ชม. (`scripts/normal_levels.py` → `data/normal_levels.json` + `data/station_history.json`)

## Forecast รายวัน 90 วัน (เลือกวันได้บน timeline)

กราฟทุกสถานีครอบคลุมย้อนหลัง 60 วัน (เส้น teal = วัดจริง) และล่วงหน้า 90 วัน (เส้นส้มประ = คาดการเชิงสถิติ + แถบช่วงคาด lo-hi) · เส้นประฟ้า = ระดับปกติ · เส้นประแดง = เกณฑ์ · เส้นแบ่งเทา = ขอบ tier

โมเดล (`scripts/forecast_days.py`): lag-route hydrograph `h(t) = h(t-1) + rise − drain`

- **rise** = wave จากส่วนเกินเหนือตลิ่งบางปะอิน ×0.30 (lag 1 วัน/ตอน, ตัวขับหลักตอนมวลน้ำเหนือมา) + ฝนเหนือ (lag 3 วัน) + ฝนท้องถิ่น + momentum สถานีจากค่าเฉลี่ย 18 ชม. + น้ำไหลเข้าเขื่อนภูมิพล+สิริกิติ์ lag 3-8 วัน (ตัวแปรใหม่ 29/9/69 ยังไม่ calibrate)
- **drain** = K · recession × ตัวคูณน้ำหนุน (คำนวณจากเฟสดวงจันทร์ 1.0 น้ำแล้ง → 0.45 spring) × ส่วนเกินเหนือระดับล่าง
- **3 tier ของ input ฝน**: วัน 1-16 ใช้ NWP (Open-Meteo) / วัน 17-35 ใช้ Seasonal API (ECMWF SEAS5) เรียบ 5 วัน / วัน 36-90 เป็นสถิติฤดูกาล อ่านเป็นแนวโน้มเท่านั้น
- h0 ของทุกสถานี = ค่าเฉลี่ย 18 ชม. (dedupe ตาม timestamp ค่าอ่าน) เพื่อกลบวัฏจักรน้ำหนุนและค่า stale
- ค่าเริ่มต้น K อิงสถิติ recession ปี 2554 (rain_coef ปรับสเกลใหม่ 28 ก.ย. เพราะค่าเดิมสูงผิดสัดส่วน): จะถูกแทนด้วยค่า fit จากประวัติ snapshot ของเราเองเมื่อสะสมพอ
- ความไม่แน่นอนสะสม ±(8 + 9·i) ซม. มีเพดาน 90–100 ซม. และขยายเพิ่มตาม tier (รวมสูงสุด ~±1.9 ม. ที่วันที่ 90)

ทุกค่า forecast เป็นการคาดการเชิงสถิติ ไม่ใช่พยากรณ์ทางการ รายละเอียดครบใน `docs/FORECAST.md`

เป้าหมายถัดไปของโปรเจกต์คือติดตามเขื่อนทั่วประเทศและเขื่อนต่างประเทศที่เกี่ยวข้อง พร้อมพยากรณ์ระดับน้ำที่แม่นขึ้น สรุปให้คนที่ clone repo ไปทำต่อ:

- ข้อมูลเขื่อนใหญ่ทั้งประเทศ (RID + EGAT) มีอยู่แล้วใน API เดียวกับที่โปรเจกต์ใช้ (`analyst/dam`) สคริปต์เก็บลง snapshot รายชั่วโมงแล้วใน field `dams_all` ตั้งแต่ Sep 29, 2026 คนต่อยอดแค่รอข้อมูลสะสมแล้ว fit โมเดลจากประวัติจริง
- ไม่มีเขื่อนต่างประเทศที่มีผลต่อน้ำกรุงเทพฯ เพราะลุ่มเจ้าพระยาอยู่ในไทยทั้งสาย เขื่อนต่างชาติที่เกี่ยวกับไทยคือกลุ่มแม่น้ำโขง (กระทบอีสานและเมืองริมโขงตอนบน ไม่ใช่กรุงเทพฯ) ดูหัวข้อเขื่อนต่างประเทศใน `docs/DATA_SOURCES.md`
- แนวทางไล่ระดับความแม่น: fit พารามิเตอร์จาก snapshot ที่สะสม แล้วใส่ dam release เป็น input แล้วเทียบกับ GloFAS กับ Google Flood Hub แล้ว LightGBM และ LSTM ตามลำดับ รายละเอียดเต็มอยู่ใน `docs/FORECAST.md`
